# 인센티브

하루 오전·오후 작업 건수를 적으면 하루·월 합계와 인센티브가 자동으로 계산되는 웹앱이에요. 깃허브 페이지에 올려 두고, 갤럭시 폰 브라우저에서 '홈 화면에 추가'해 앱처럼 씁니다.

## 되는 것

- 오늘: 오전·오후 건수를 −/+ 버튼이나 숫자로 입력, 오늘 합계와 이번 달 누적·인센티브
- 달력: 날짜마다 건수 보기, 지난 날짜 고치기, 월 합계·근무일·하루 평균
- 통계: 최근 6개월 건수 막대, 달마다 인센티브·하루 평균·최고 기록
- 설정: 인센티브 계산 방식을 언제든 바꾸기
  - 건당 지급 / 기준 넘은 만큼 지급 / 구간별 지급 / 매출 기준 % 지급
  - 매출은 '건수 × 건당 매출' 또는 '매달 직접 입력', %는 '매출 전체' 또는 '기준 넘은 금액만'
  - 적용 시작 달을 정하면 그 달부터 새 기준으로 계산하고, 지난 달은 그때 기준 그대로
- 구글 계정 자동 백업: 가계부와 같은 Firebase 프로젝트, 기록은 `users/{내 계정}/geonsu-*` 에 따로 저장
- 인터넷이 없어도 열리고, 기록은 폰 안에 먼저 저장

정산 기간은 매월 1일 ~ 말일이에요.

## 폰에 설치하기

1. 저장소 **Settings → Pages**에서 Source를 **GitHub Actions**로 둡니다.
2. 코드가 올라가면 Actions 탭에서 배포가 끝날 때까지 기다립니다 (1~2분).
3. 갤럭시의 크롬이나 삼성 인터넷에서 `https://hjpark831-source.github.io/geonsu/` 를 엽니다.
4. 메뉴에서 **홈 화면에 추가**를 누릅니다.

## 개발
